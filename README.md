# 집중 타이머

브라우저에서 바로 사용할 수 있는 한국어 기반 로컬 TODO 타이머 앱입니다.

## 프로젝트 소개

집중 타이머는 할 일을 관리하면서 실제로 얼마나 집중했는지 세션 단위로 기록할 수 있도록 만든 앱입니다.  
한 번에 하나의 작업에만 타이머를 실행할 수 있고, 완료된 세션은 오늘 기록, 이번주 요약, 요일별 기록, 최근 날짜별 기록으로 확인할 수 있습니다.

모든 데이터는 브라우저의 `localStorage`에 저장되며, 새로고침 후에도 가능한 범위에서 할 일, 타이머 상태, 기록, 설정이 복원됩니다.

## 현재 구현된 기능

- 할 일 추가, 수정, 삭제
- 할 일 완료 상태 토글
- `전체 / 미완료 / 완료` 필터
- 한 번에 하나의 작업만 실행 가능한 인터랙티브 원형 타이머
- 드래그/터치로 타이머 시간 설정
- 시작, 일시정지, 초기화, 완료 상태 분리
- 완료 세션 기록 저장
- 오늘 기록, 이번주 기록, 요일별 기록, 최근 날짜별 집중 기록 화면
- `localStorage` 기반 상태 저장 및 복원
- 완료 사운드 on/off 설정
- 브라우저 알림 권한 요청 및 백그라운드 완료 알림
- 완료 시 화면 내 토스트 피드백
- 개발자에게 수정 요청하기 카드
- analytics abstraction 구조와 기본 이벤트 정의

## 폴더 구조

```text
src/
  components/   타이머, 기록, 설정, 피드백 UI 컴포넌트
  hooks/        타이머 상태, 저장, 완료 피드백 관련 훅
  pages/        타이머 화면, 기록 화면
  types/        앱 상태와 데이터 타입
  utils/        시간, 세션, 저장, analytics, 설정 유틸
  App.tsx       앱 상태 조합과 주요 이벤트 처리
  App.css       전체 스타일
public/
  sounds/       완료 알림 사운드 파일
```

## 핵심 동작 방식

- 타이머는 timestamp 기반으로 동작하며, 단순한 1초 누적 방식이 아니라 `startedAt`과 현재 시각 차이로 남은 시간을 계산합니다.
- `일시정지`는 현재 진행 시간을 누적하고, `초기화`는 이번 진행 시간을 버린 뒤 설정 시간으로 되돌립니다.
- `완료` 시에는 세션 기록이 생성되고, 날짜/요일 집계는 실제 완료 시각 기준으로 남습니다.
- 브라우저가 백그라운드에 있더라도 완료 판정은 가능한 범위에서 예상 완료 시각 기준으로 처리합니다.
- 저장 데이터에는 `schemaVersion`이 포함되며, 일부 필드가 깨져도 가능한 데이터부터 복구하도록 구성되어 있습니다.

## 제한 사항과 참고

- 브라우저 알림은 사용자가 권한을 허용한 경우에만 동작합니다.
- 모바일 브라우저, 특히 iOS Safari에서는 백그라운드 실행과 오디오/알림 정책에 제약이 있을 수 있습니다.
- analytics는 개발 환경에서만 기본 콘솔 로그를 출력하며, 운영 빌드에서는 기본적으로 no-op입니다.
